# 질문 텍스트 보완

문제지 PDF에서 표가 평탄화되며 질문이 표 밖으로 밀려난 문항의 질문 텍스트다.
`backend/search/catalog.py` 가 카탈로그를 만들 때 이 표를 병합한다.

**출처는 문제지 원문**이며 요약이 아니라 표기 그대로다. 자동 추출이 되는 문항은
여기 넣지 않는다 — 중복 관리가 되면 원문과 어긋나기 쉽다.

새 자료가 들어와 추출 실패 문항이 생기면 `catalog.py` 실행 시 목록으로 출력되니
그 문항만 여기 추가하면 된다.

아래 5건은 자동 추출은 됐으나 질문이 **중간에서 잘린** 경우다(괄호가 닫히지 않음).
`catalog.py` 가 그런 문항을 의심 목록으로 출력한다.

| 앵커 | 질문 |
|---|---|
| `G-S01-M01-Q04` | 공직자 재산등록 시스템 고도화 사업에 투입되는 예산은 얼마입니까? (억 원 단위, 숫자만 입력해주세요) |
| `B-S01-M01-Q03` | 5건 전체 본문에서 `(숫자)억\s*원` 형태로 표현된 금액의 합계는 얼마입니까? (억 단위 정수, 반올림) |
| `B-S02-M02-Q04` | 전처리 후 데이터에서 라벨 1(시민참여수 ≥ 중앙값) 행의 총사업비_억원 평균은? (반올림 정수) |
| `B-S03-M01-Q01` | 본문에 「○○법」 형태로 인용된 외부 법령은 모두 몇 종류입니까? (같은 법령을 여러 번 인용해도 한 종류로만 셉니다) |
| `B-S05-M01-Q02` | 본문에서 총점검건수의 두 값 사이 차이는 얼마입니까? (큰 값 − 작은 값, 양수) |
