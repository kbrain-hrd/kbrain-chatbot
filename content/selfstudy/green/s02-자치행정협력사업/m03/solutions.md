[연습02·그린] 3과목 해설 — 정적 웹페이지 (산출물 평가,
연습세트)
ℹ️ 연습세트 — 응시자에게 공개됩니다.
풀이 도구: ChatGPT/Claude/v0/Lovable 자유.
소요 시간 가이드: AI 활용 약 25~30분 + 배포 5~10분.
🧭 풀이 흐름
1단계 — AI에 일괄 요청
권장 프롬프트:
첨부 신청목록.json (지자체 10건)을 읽어 표로 표시하는 단일 페이지 사이트를 HTML/CSS/JS로 만들어
줘. 표 컬럼은 지자체명·인구수·신청액·한도액·판정 5개. 한도액은 인구수×10으로 계산하고, 신청액이 한
도액보다 크면 "반려", 작거나 같으면 "승인"으로 자동 표시. 그리고 화면 위쪽에 승인 건수·반려 건수·승
인 신청액 합계 3가지 요약 수치를 큼직하게 표시해줘. 모바일 반응형.
2단계 — 핵심 로직 (JS)
const data = await fetch('신청목록.json').then(r => r.json());
const results = data.map(item => ({
 ...item,
 한도액: item.인구수 * 10,
 판정: item.신청액 > item.인구수 * 10 ? '반려' : '승인'
}));
const 승인 = results.filter(x => x.판정 === '승인');
const 반려 = results.filter(x => x.판정 === '반려');
const 승인합 = 승인.reduce((s, x) => s + x.신청액, 0);
3단계 — 배포
Netlify 드래그&드롭 → URL 복사 → 제출물.md 에 기재.
