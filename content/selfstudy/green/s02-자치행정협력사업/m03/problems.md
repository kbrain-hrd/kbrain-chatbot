[연습세트02·그린] 3과목 — 업무 자동화 (연습)
시험 종류: 연습 (정답·해설 공개) / 등급: 그린 / 제한시간: 40분
배점: 100점 (산출물 평가 — 단답 문항 없음)
사용 도구: ChatGPT/Claude/v0/Lovable 등 자유. HTML/CSS/JS 정적 페이지 + Netlify·Vercel 등 무료 정
적 배포.
시나리오
당신은 자치행정 협력사업 담당자입니다. 지자체 10곳이 신청한 협력사업 예산을 한도액 초과 여부로 자동 판
정하는 페이지를 만들어 Netlify(또는 Vercel)에 배포합니다.
심사 규칙: 한도액 = 인구수 × 10, 신청액이 한도액보다 크면 반려, 같거나 작으면 승인.
생성AI에게 첨부 JSON을 보여주고 "지자체별 승인/반려 자동 판정 페이지 만들어줘" 한 줄 요청이면 30분이
면 끝납니다. 실전 4세트의 정적 페이지 유형을 미리 연습하는 작업입니다.
필수 기능
1. 페이지 로드 시 첨부 신청목록.json 을 읽어 지자체 10건을 표로 표시 (지자체명·인구수·신청액·한도액·판
정 5컬럼)
2. 판정 컬럼에 "승인" 또는 "반려"가 자동 표시되도록 (한도액 = 인구수 × 10, 신청액 > 한도액 → 반려)
3. 화면에 승인 건수 / 반려 건수 / 승인 신청액 합계 3가지 요약 수치 표시
첨부 파일 안내
신청목록.json — 지자체 10건 (지자체명·인구수·신청액)
제출 (100점)
제출물.md 한 장 + 소스 파일 동봉.
1. 배포 URL 1줄 — https://xxxxx.netlify.app 형태
2. 소스 파일 — index.html (또는 zip)
3. 사용 AI 도구 + 메모 — 어느 AI로 만들었는지 + 어떻게 구현했는지 3~5줄
채점은 채점자가 URL에 직접 접속해 동작을 확인하는 방식입니다. 단답으로 답할 문항은 없습니다.
파일명 내용
제출물.md 배포 URL 1줄 + 사용 AI 도구 + 구현 메모 (3~5줄)
소스.zip index.html , style.css , app.js (또는 사용 도구 export 결과)
