[연습03·그린] 2과목 데이터분석 — 해설
자원봉사프로그램.csv (3,621행 · 15컬럼) 분석 · 정답 및 풀이
정제 기준
봉사분야 또는 봉사자유형 컬럼이 빈 셀인 행을 제거한다. 실제 CSV에서 해당 두 컬럼(봉사분야·봉사자유
형)에는 빈 셀이 하나도 없어 제거되는 행이 없으므로, 정제 후 행수는 원본과 같은 3,621행이다.
문항별 정답
문항 정답 풀이 요약
1 3621 빈 셀 행이 없어 제거되는 행 없음 → 원본 3,621행 유지.
2 22 봉사분야 컬럼의 고유값(unique) 종류 수 = 22종.
3 3 봉사자유형 고유값 = "성인", "성인 청소년", "청소년" 3종.
4 생활편의 봉사분야별 건수 최다 = 생활편의(1,245건). 2위 기타(738건).
5 1435 봉사자유형에 "청소년" 포함 = 성인 청소년(1,364)+청소년(71)=1,435.
풀이 절차 (AI/노코드 공통)
1) CSV를 UTF-8(BOM)로 불러온다. 2) 봉사분야·봉사자유형이 빈 셀인 행을 제거한다(본 데이터는 해당 0
건). 3) 남은 행수를 센다(문항1). 4) 두 컬럼의 고유값 종류 수를 센다(문항2·3). 5) 봉사분야를 값별로 집계
해 최다 분야를 찾는다(문항4). 6) 봉사자유형에 "청소년" 문자열이 포함된 행을 센다(문항5).
참고: Python(pandas) 예시
import pandas as pd
df = pd.read_csv("자원봉사프로그램.csv", encoding="utf-8-sig")
c = df.dropna(subset=["봉사분야","봉사자유형"])
len(c) # 문항1 -> 3621
c["봉사분야"].nunique() # 문항2 -> 22
c["봉사자유형"].nunique() # 문항3 -> 3
c["봉사분야"].value_counts().idxmax() # 문항4 -> 생활편의
c["봉사자유형"].str.contains("청소년").sum() # 문항5 -> 1435
