[연습세트 01 · 그린] 3과목 해설 (연습 — 공개)
등급: 그린 — AI 챗봇을 자유롭게 활용하는 것을 전제로 한 풀이 전략입니다.
추천 풀이 전략 (전체 소요 시간 약 20분)
1단계 — AI로 HTML 생성 (약 10분)
첨부/보도자료_125874.md 내용을 복사한 뒤, AI 챗봇에 아래 프롬프트를 입력한다.
AI 프롬프트 예시
아래 보도자료 내용을 바탕으로 HTML 페이지를 만들어 주세요.
[보도자료 전체 내용 붙여넣기]
조건:
1. <title> 태그에 "인사교류" 문구 포함
2. 페이지 상단에 보도자료 제목을 헤더로 표시
3. "인사 인센티브" 섹션과 "채용제도 개선" 섹션을 구분하여 표시
4. 각 섹션의 핵심 내용을 <ul> 목록으로 정리
5. 장관 발언을 <blockquote>로 강조
6. CSS를 <style> 태그에 포함, 깔끔한 디자인
AI가 생성한 코드를 index.html 로 저장한다.
2단계 — Netlify 배포 (약 5분)
1. netlify.com → 회원가입 또는 로그인
2. 대시보드 중앙 박스에 index.html 드래그&드롭
3. 자동 배포 후 URL 생성 (예: https://abc123.netlify.app )
4. URL 복사
3단계 — 제출 (약 2분)
1. 메모장에 URL 붙여넣기
2. 배포_URL.txt 로 저장 후 제출

채점 항목별 확인 포인트
항목 확인 방법
URL 접근 브라우저에서 URL 입력 → 정상 로드 여부
페이지 제목 브라우저 탭에 "인사교류" 또는 "채용제도" 포함 여부
섹션 구분 인사 인센티브·채용제도 개선 내용이 별도 구분되어 있는지
목록 표시 각 섹션에 핵심 사항이 목록 형태로 나열되어 있는지
인용구 장관 발언이 강조 또는 인용 형태로 표시되어 있는지
흔한 실수
실수 예방법
HTML만 만들고 배포 안 함 Netlify URL 생성까지 완료 후 제출
섹션을 구분 없이 나열 AI에게 "두 섹션으로 나눠달라"고 명시
장관 인용구 누락 프롬프트에 <blockquote> 명시
URL 만료 채점 기간 동안 Netlify 계정 유지
