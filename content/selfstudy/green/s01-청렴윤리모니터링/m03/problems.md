[연습세트01·그린] 3과목 — 자동화
시험 종류: 연습 (정답·해설 공개)
등급: 그린 | 제한시간: 40분 | 배점: 100점 (전부 제출파일 채점)
허용 도구: AI 챗봇(ChatGPT · Claude · Gemini 등) 자유 활용
시나리오
당신은 행정안전부 지방인사제도과 소속 담당자다.
팀장이 최근 발표한 보도자료 내용을 시민이 쉽게 읽을 수 있도록
웹 페이지로 제작해 배포하라는 지시를 내렸습니다.
첨부 파일 안내
파일명: 첨부/보도자료_125874.md
내용: 공무원 인사교류 활성화 및 채용제도 개선 관련 행정안전부 보도자료
AI 챗봇에 파일 내용을 붙여넣고 HTML 페이지를 생성하도록 요청한 뒤,
Netlify 또는 GitHub Pages로 배포하고 URL을 제출해주세요.
과제 요구사항
아래 항목이 모두 포함된 HTML 페이지를 제작합니다.
항목 설명
페이지 제목 <title> 태그에 "인사교류" 또는 "채용제도" 문구 포함
보도자료 제목 페이지 상단에 보도자료 H1 제목 표시
2개 섹션 구분 ① 인사 인센티브, ② 채용제도 개선 내용을 각각 섹션으로 구분
주요 내용 목록 각 섹션의 핵심 내용을 목록( <ul> 또는 <ol> ) 형태로 표시
장관 인용구 윤호중 장관 발언을 인용구( <blockquote> ) 또는 강조 형태로 표시
배포 방법 (둘 중 하나 선택)
Netlify (권장)
1. netlify.com → 로그인
2. 대시보드에 HTML 파일 드래그&드롭
3. 자동 생성된 URL 복사
GitHub Pages
1. 저장소 생성 → index.html 로 업로드
2. Settings → Pages → 배포 완료 후 URL 복사
