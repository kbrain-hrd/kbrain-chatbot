[연습세트02·블루] 3과목 — 셀프스터디용 해설
셀프스터디용 공개 해설입니다. 풀이 후 채점 기준으로 활용하세요.
자동화 과목은 단답 문항 없음. 산출물 ① 정적 페이지 + 산출물 ② Python 도구 두 가지를 직접 확인하
여 채점.
산출물 ① 정적 페이지 채점 가이드 (50점)
채점 절차
1. 응시자 zip에서 배포 _URL.txt를 읽어 URL 1줄 확인 (앞뒤 공백 자동 제거 후)
2. 브라우저로 URL 접속 — 빈 페이지·404·인증 요구 없이 즉시 표시되어야 함
3. 첨부 데이터의 카드·검색·필터가 화면에 표시되고 동작하는지 확인
4.
부분 작동 처리
URL은 OK지만 데이터 카드가 안 보임 (네트워크 경로 오류) → 데이터 표시 항목 절반 점수
반 점수
검색·필터가 동작 안 함 → 데이터 표시 항목 절반 점수
산출물 ② Python 자동화 도구 채점 가이드 (50점)
채점 절차
1. 응시자 zip에서 solution.py· 결과 _*.csv· 제출물 .md 위치 확인
2. 같은 폴더에 첨부 데이터(JSON/CSV)를 두고 python solution.py [ 인자 ] 실행
3. 에러 없이 종료 + 의도한 결과 산출 (콘솔 출력 + CSV 생성)
4. 결과 _*.csv의 헤더·행 수가 문제지 요구와 일치하는지 확인
채점자 참고용 실행 예시
문제지에 명시된 산출물 ② 실행 시나리오를 그대로 따라 실행한 뒤, 응시자의 결과 _*.csv 행 수와 비교합니
다.
$ python solution.py [ 응시자가 사용한 인자 ]
[OK] 결과 N 건 저장 → 결과 _*.csv
부분 작동 처리
solution.py 실행 시 에러 (인코딩·모듈 누락·인자 누락) → 실행 항목 0점
실행 OK지만 결과 CSV 빈 파일·헤더만 있음 → 결과 항목 절반 점수
결과 _*.csv는 동봉됐는데 solution.py 누락 → 산출물 ② 0점 처리
잡음 주의
응시자가 페이지 또는 Python 도구 중 하나만 제출한 경우 해당 산출물 0점
URL은 시험 기간(제출 후 7일) 동안 접근 가능해야 함
외부 리소스가 CORS 또는 임베드 차단으로 부분 작동 시 그 항목만 절반 점수
AI 도구가 자동 생성한 코드라 라이브러리 import 누락·Windows 경로 처리 등의 사소한 오류가 자주 발생
— 응시자에게 -3 정도 감점
AI 보조 활용 가이드
산출물 ①: 응시자가 v0·Lovable·ChatGPT에 첨부 데이터 + 외부 리소스 요구를 한 번에 요청해 생성하는
것이 정상
산출물 ②: 응시자가 ChatGPT/Claude에 "이 JSON/CSV에서 키워드 N개 추출해서 결과 CSV 저장하는 스크
립트 짜줘" 요청
채점자는 산출물의 동작만 확인. 코드 품질·스타일은 평가 대상이 아님.
