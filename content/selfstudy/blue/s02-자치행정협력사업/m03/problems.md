[연습세트02·블루] 3과목 — 자동화
시험 종류: 연습 (정답·해설 공개)
등급: 블루 | 제한시간: 40분 | 배점: 100점 (산출물 평가)
사용 도구: AI 자유 활용 (ChatGPT · Claude · Gemini 챗봇 · Lovable · v0 등). 정적 페이지 + Python 두 가
지 산출물.
시나리오
당신은 자치행정 협력사업 담당자입니다. 지자체 협력사업 신청 자료를 활용해 다음 두 가지를 만들어주세요.
1. 정적 웹 페이지 — 신청 자료 카드 + Google Sheets 임베드를 표시하는 페이지를 무료 호스팅에 배포
2. Python 자동화 도구 — 신청 자료 파일을 지자체별로 자동 분류·정리하는 스크립트
첨부 파일 안내
신청목록.json — 지자체 협력사업 신청 데이터
신청서/ — 지자체별 신청서 마크다운 파일들
산출물 ① — 정적 페이지 + 외부 리소스 (50점)
항목 설명
신청 카드
표시
신청목록.json 을 읽어 지자체·사업명·예산을 카드로 표시
자동 판정 한도액 초과 여부를 색상으로 표시 (승인/반려)
외부 리소
스 (필수)
Google Sheets 임베드 — 신청 자료 핵심 정보(지자체·사업명·예산)를 Google Sheets로 정리한 뒤
<iframe> 으로 페이지에 임베드 (Sheets의 "파일 → 공유 → 웹에 게시 → 임베드 코드" 사용)
배포 Netlify · Vercel · v0 자체 호스팅 중 자유
산출물 ② — Python 자동화 도구 (50점)
solution.py 한 파일로, 첨부 신청서/ 폴더의 파일을 지자체별로 자동 분류해
를 작성해주세요.
$ python solution.py
[OK] 신청서 10건 지자체별 분류 → 출력_지자체별/
 · 서울특별시 2건
 · 부산광역시 1건
 · ...
하위 폴더로 복사하는 도구
