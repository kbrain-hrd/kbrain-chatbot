[연습세트04·블루] 2과목 — 데이터분석 (연습)
시험 종류: 연습 (정답·해설 공개) / 등급: 블루 / 제한시간: 40분
배점: 100점 (단답 문항 90 + 제출파일 10)
사용 도구: Python(pandas·scikit-learn) + AI 보조.
시나리오
공공시설 예약현황과 시설유형 통계 2개 파일을 결합하여, 예약의 노쇼(예약부도) 여부를 예측하는 분류 모델
을 만들고 비교해주세요.
첨부: 공공시설_예약현황.csv (1,500건) + 시설유형_통계.csv (6개 유형)
문제 (90점, 부분점수 가능)
데이터 처리 규칙 (정답 산출의 기준입니다)
- 두 CSV를 시설유형 키로 merge 해주세요.
- 라벨: 노쇼여부 가 "노쇼"인 행을 1, 나머지를 0으로 정의합니다.
- 이상치 처리: 예약대기일 이 0 미만이거나 결측인 행을 제거해주세요.
