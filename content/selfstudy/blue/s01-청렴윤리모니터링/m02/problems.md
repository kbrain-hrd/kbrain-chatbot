데이터 처리 규칙 (정답 산출의 기준입니다)
- 두 CSV를 기관코드 키로 inner merge 해주세요.
- 결측치 처리: dropna() 로 결측값 행을 제거해주세요.
- 이상치 처리: 설문인원 과 평균처리일수 컬럼에 대해 IQR 방식 (Q1 - 1.5*IQR 미만 또는 Q3 + 1.5*IQR
초과)으로 이상치 행을 제거해주세요.
- 라벨: 부패위험 은 아래 수식과 시드 251을 사용해 응시자가 직접 생성합니다 (정제 완료 데이터 순서
그대로 적용).
import numpy as np
rng = np.random.default_rng(251)
risk = (-0.45 * 청렴지수 + 0.08 * 신고건수
 - 0.012 * 처리율 + 0.04 * 평균처리일수)
risk_n = (risk - risk.mean()) / risk.std() # 표준화
noise = rng.normal(0, 0.5, len(정제데이터))
