시나리오
당신은 행정안전부 디지털정부실 사무관입니다. (가상) 「행정정보 통합관리 기본법」(본칙 14조) 본문을 활용
해 다음 두 가지를 만들어주세요.
1. 정적 웹 페이지 — 조항 카드 검색 + 외부 리소스(분야별 아이콘 이미지)를 표시하는 페이지를 무료 호스
팅에 배포
2. Python 자동화 도구 — 키워드를 입력하면 해당 조항만 골라 CSV로 추출하는 스크립트
첨부 파일 안내
가상_행정정보통합관리법_본문.md — 가상 법령 전문
조항데이터.json — 본문에서 추출한 조항 15개 배열 ( {조, 제목, 본문} 3필드)
이미지/카드뉴스1~4.png — 페이지에 임베드해야 하는 카드뉴스 이미지 (산출물 ① 외부 리소스로 최소
3장 사용)
산출물 ① — 정적 페이지 + 외부 리소스 (50점)
항목 설명
조항 카드 표
시
조항데이터.json 을 읽어 조 번호·제목·본문 요약을 카드로 표시
키워드 검색 제목 또는 본문으로 필터링 + "결과 N건" 표시

(필수)

<img> 태그로 직접 임베드 (최소 3장 이상 노출)
배포 Netlify · Vercel · v0 자체 호스팅 중 자유
산출물 ② — Python 자동화 도구 (50점)
solution.py 한 파일로, 사용자가 키워드를 입력하면 해당 키워드가 포함된 조항만 CSV로 저장하는 도구를
작성해주세요.
