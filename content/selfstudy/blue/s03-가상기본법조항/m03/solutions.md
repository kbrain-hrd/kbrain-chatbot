[연습세트03·블루] 3과목 — 셀프스터디용 해설
채점자·제작자 전용. 자동화 과목은 단답 없음. 산출물 ① 정적 페이지 + 산출물 ② Python 도구를 직접 확인하여
채점.
산출물 ① 정적 페이지 채점 가이드 (50점)
배포_URL.txt URL 접속 — 빈 페이지·404·인증 없이 즉시 표시
조항데이터.json 의 조항 카드·키워드 검색·"결과 N건" 동작 확인
외부 리소스: 이미지/카드뉴스1~4.png 중 최소 3장이 <img> 로 정상 표시되는지 확인
부분 작동: 카드뉴스 이미지가 3장 미만이거나 깨짐 → 외부 리소스 항목 절반. 검색·필터 미동작 → 데이터 표시
항목 절반.
산출물 ② Python 자동화 도구 채점 가이드 (50점)
solution.py · 조항데이터.json 을 같은 폴더에 두고 python solution.py "키워드" 실행
에러 없이 종료 + 키워드 포함 조항만 추려 결과_<키워드>.csv(헤더 조·제목·본문) 생성
콘솔에 결과 건수 출력
$ python solution.py "기본계획"
[OK] N건 저장 → 결과_기본계획.csv
부분 작동
· 실행 에러(인코딩·모듈·인자 누락) → 실행 항목 0점
· 실행 OK지만 결과 CSV 빈 파일·헤더만 → 결과 항목 절반
· 결과_*.csv 만 있고 solution.py 누락 → 산출물 ② 0점
