# 미확정 사항

구현 시작 전 확인이 필요한 항목입니다.
실제 자료 확인 결과는 [05-data-survey.md](05-data-survey.md) 참조.

---

## 1. 필요 자료

| 자료 | 상태 | 필요한 이유 |
|---|---|---|
| 예제문제 PDF (문제·해설·답안지) | ✅ 수령 (2026-08-01) | 그린·블루 각 5세트 × 3과목 |
| 문항 첨부파일 (CSV·MD·JSON) | ✅ 수령 | 코드 실행 검증에 사용 |
| 운영 자료 | ✅ 수령 | 준비안내(hwpx), CBT가이드, 종합안내서, 셀프학습가이드 |
| 구글시트 URL + 접근 권한 | ❌ 미수령 | 질문 분포 확인, 연동 |

**1단계(변환)는 즉시 시작 가능합니다.** 구글시트는 5단계 전까지 필요합니다.

## 2. 미결정 사항

### 2-1. 검수를 어디서 할 것인가

| 안 | 장점 | 단점 |
|---|---|---|
| **시트에서 직접** (권장) | 긴 답변과 근거를 한눈에 보며 수정. 도구를 늘리지 않음 | 실시간성은 알림에 의존 |
| 슬랙 버튼 | 빠른 승인/반려 | 긴 답변 수정에 불편 |
| 별도 검수 화면 | 문제 원문·해설·초안을 나란히 표시 | 개발 범위 증가 |

**권장:** 슬랙으로 "N건 검수 대기" 알림만 받고, 검수는 시트에서 수행.

> 상태: 미결정

### 2-2. 운영 관련 자료의 형태

문서 파일 / 구글시트 / 노션 / 정리된 것 없음 — 어느 쪽인지에 따라
수집 방식과 작업량이 크게 달라집니다.

"정리된 것이 없다"면 자주 나오는 운영 질문부터 문서화하는 작업이 선행되어야 합니다.

> 상태: 미결정

### 2-3. 3과목(자동화) 질문 처리

3과목은 단답 정답이 없고 루브릭으로 채점합니다. 삼각 검증 구조가 성립하지 않습니다.

질문도 "정답이 뭔가요"가 아니라 "이렇게 만들면 점수 되나요"에 가까워,
근거가 정답이 아니라 채점 기준표입니다.

- 루브릭 항목을 근거로 제시하는 별도 경로가 필요
- 산출물 판정은 사람이 해야 하므로, 초안은 "기준 안내"까지만

> 상태: 미결정 (4단계 전 결정)

### 2-4. 실전 세트 문의 대응

수령한 자료는 전부 "연습세트(정답·해설 공개)"입니다.
실전 세트 문제에 대한 질문이 들어올 경우의 방침이 필요합니다.

> 상태: 미결정

## 3. 확정된 사항

기록용으로 남깁니다.

| 항목 | 결정 |
|---|---|
| 정답의 근거 | 문제 원문 (해설·과거답변은 검수 대상) |
| 자동 발송 여부 | **하지 않음.** 사람 승인 후 등록 |
| 최종 저장소 | 구글시트 |
| 알림 채널 | 슬랙 |
| 교재 vs 현재 기준 충돌 | 교재 기준 정답 + 현재 기준 병기 |
| 문서 포맷 | PDF → 마크다운 전환 |
| 근거 없을 때 | 초안 생성하지 않고 담당자에게 알림 |
| 과목 | AI |
| MVP 범위 | **문제 관련 + 운영 관련 모두 포함** (2026-08-01 결정. 운영 자료 수령 완료) |
| 검색 구조 | **벡터 검색 미사용.** 앵커 기반 특정+조회 (문항 100개 규모 — [05](05-data-survey.md) 2-3) |
| 임베딩 모델 | 불필요 (검색 구조 결정에 따라 자동 해소) |
| 앵커 스킴 | `G-S01-M02-Q03` (등급-세트-과목-문항). 등급 필수 |
| PDF 추출기 | **pypdfium2** 기준. pdfplumber는 대조군 |

## 4. 남은 리스크

| 리스크 | 대응 |
|---|---|
| PDF 변환 시 숫자·표 손상 | **실제로 발생 확인됨.** 두 추출기 대조로 위험 지점 자동 탐지 ([05](05-data-survey.md) 3장) |
| 그린·블루 혼동 | 같은 세트명·다른 정답. 앵커에 등급 포함으로 차단 |
| 문제 자체에 오류가 있는 경우 | 삼각 검증에서 "전부 갈림"으로 탐지 → 사람 확인 |
| 검수 부담이 수기 작성보다 커지는 경우 | 초안 무수정 승인률을 측정해 판단. 낮으면 범위 축소 |
| 3과목은 정답이 없어 검증 불가 | 루브릭 기반 별도 경로 (2-3) |
