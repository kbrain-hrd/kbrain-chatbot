| 과거 질의응답 시트 | ✅ 수령 (2026-08-01) | 질문 151건 — [05](05-data-survey.md) 6장 |

**1단계(변환)는 즉시 시작 가능합니다.** 구글시트는 6단계 전까지 필요합니다.

### 자료는 계속 추가됩니다

위 목록은 1차 수령분이며, 이후로도 자료가 계속 들어옵니다 (2026-08-01 확인).

→ 인제스트는 **일회성 변환 스크립트가 아니라 재실행 가능한 파이프라인**이어야 합니다.
자료가 추가될 때마다 전체를 다시 돌려도 결과가 같아야 하고(멱등), 앵커 카탈로그도
증분 갱신되어야 합니다. 처음부터 그렇게 만들지 않으면 나중에 갈아엎게 됩니다.

## 2. 미결정 사항

### 2-1. 검수를 어디서 할 것인가

> 상태: **결정 (2026-08-01).** 승인은 슬랙, 수정은 시트.

당초 권장안은 "슬랙은 알림만, 검수는 시트에서"였으나 뒤집혔습니다.
**승인 행위 자체가 슬랙에서 일어납니다.**

```
시트에 질문 등록
      ↓ (감지)
슬랙 카드: 초안 전문 + 근거 + 플래그 + [승인] [반려] + 시트 링크
      ↓
그대로 OK  → 슬랙에서 승인 → 시트에 최종답변 등록
손볼 게 있음 → 시트 링크로 이동해 수정 후 승인
```

**왜 이렇게 나눴는가.** 검수 결과는 승인 / 수정 후 승인 / 반려 세 가지인데,
슬랙 버튼은 승인·반려에는 빠르지만 **긴 답변을 고쳐 쓰기에는 불편**합니다.
그런데 초안이 항상 완벽할 수는 없으므로 실사용에서는 "수정 후 승인"이 가장 잦을 것으로 봅니다.

→ 승인 경로는 슬랙 하나로 유지하되, **수정만 시트로 넘깁니다.**
알림을 보고 다시 시트를 열어 상태를 찾아 들어가는 왕복을 없애는 것이 목적입니다.

### 2-2. 운영 관련 자료의 형태

> 상태: **해소 (2026-08-01).** 자료 수령으로 자동 해결.

문서 파일 형태로 4종 수령했습니다 — 준비안내(hwpx), CBT 가이드(PDF),
종합안내서(PDF), 셀프학습가이드(HTML). "정리된 것이 없어 문서화부터 해야 하는" 상황은
아니었습니다. 추출 난이도와 우선순위는 [05-data-survey 5장](05-data-survey.md) 참조.

### 2-3. 3과목(자동화) 질문 처리

3과목은 단답 정답이 없고 루브릭으로 채점합니다. 삼각 검증 구조가 성립하지 않습니다.

질문도 "정답이 뭔가요"가 아니라 "이렇게 만들면 점수 되나요"에 가까워,
근거가 정답이 아니라 채점 기준표입니다.

- 루브릭 항목을 근거로 제시하는 별도 경로가 필요
- 산출물 판정은 사람이 해야 하므로, 초안은 "기준 안내"까지만

> 상태: 미결정 (4단계 전 결정)

### 2-4. 실전 세트 문의 대응

수령한 자료는 전부 "연습세트(정답·해설 공개)"입니다.
실전 세트 문제에 대한 질문이 들어올 경우의 방침이 필요합니다.

> 상태: 미결정

## 3. 확정된 사항

기록용으로 남깁니다.

| 항목 | 결정 |
|---|---|
| 정답의 근거 | 문제 원문 (해설·과거답변은 검수 대상) |
| 자동 발송 여부 | **하지 않음.** 사람 승인 후 등록 |
| 최종 저장소 | 구글시트 |
| 알림 채널 | 슬랙 |
| **질문 유입 경로** | **시트 + 유선(전화).** 둘 다 대응 (2026-08-01 추가) |
| **주력 질문 유형** | 오답 원인 문의 · 문제 오류 제기 · 운영 문의 · 3과목 산출물 문의 |
| **문제 오류 제기 처리** | **자동 판정 금지.** 대조 결과만 제시하고 사람에게 |
| **1.5단계 검증 방식** | 해설 코드 실행 → **문제지만으로 푸는 검증**으로 교체 |
| **시트 개인정보** | **질문·답변만 추출.** 이름·소속·연락처·이메일 컬럼은 읽지 않음 |
| **공식 정답 오류 처리** | 임의 정정 금지. `official_answer_disputed` 플래그 + 경위 안내 |
| **유선 대응 인터페이스** | **웹 UI.** 담당자가 여러 명이라 CLI는 부적합 |
| **검수 위치** | **승인은 슬랙, 수정은 시트** (2-1) |
| 교재 vs 현재 기준 충돌 | 교재 기준 정답 + 현재 기준 병기 |
| 문서 포맷 | PDF → 마크다운 전환 |
| 근거 없을 때 | 초안 생성하지 않고 담당자에게 알림 |
| 과목 | AI |
| MVP 범위 | **문제 관련 + 운영 관련 모두 포함** (2026-08-01 결정. 운영 자료 수령 완료) |
| 검색 구조 | **벡터 검색 미사용.** 앵커 기반 특정+조회 (문항 100개 규모 — [05](05-data-survey.md) 2-3) |
| 임베딩 모델 | 불필요 (검색 구조 결정에 따라 자동 해소) |
| 앵커 스킴 | `G-S01-M02-Q03` (등급-세트-과목-문항). 등급 필수 |
| PDF 추출기 | 문제지·해설은 **pypdfium2**. **답안지는 두 추출기 결과 병기 후 사람이 확정** — 둘 다 서로 다른 방식으로 틀림 ([05](05-data-survey.md) 3-1) |

## 4. 남은 리스크

| 리스크 | 대응 |
|---|---|
| PDF 변환 시 숫자·표 손상 | **실제로 발생 확인됨.** 두 추출기 대조로 위험 지점 자동 탐지 ([05](05-data-survey.md) 3장) |
| 그린·블루 혼동 | 같은 세트명·다른 정답. 앵커에 등급 포함으로 차단 |
| 문제 자체에 오류가 있는 경우 | 삼각 검증에서 "전부 갈림"으로 탐지 → 사람 확인 |
| 검수 부담이 수기 작성보다 커지는 경우 | 초안 무수정 승인률을 측정해 판단. 낮으면 범위 축소 |
| 3과목은 정답이 없어 검증 불가 | 루브릭 기반 별도 경로 (2-3) |
