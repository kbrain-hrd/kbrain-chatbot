# 운영 — 회사 PC에 설치하기

시트 경로(질문 감지 → 초안 → 슬랙 승인 → 시트 기록)는 **누군가 항상 켜두어야 동작합니다.**
시트를 주기적으로 읽고 슬랙 버튼을 기다리는 구조라서요.

이 문서는 담당자 PC에 설치해 **로그온할 때마다 자동으로 뜨게** 만드는 절차입니다.

> 유선 대응 웹 UI(5단계)는 이 문서와 무관합니다. 필요할 때 띄우면 됩니다.

---

## 1. 무엇이 켜져 있어야 하는가

한 프로그램만 켜두면 됩니다 (`backend/service.py`).

```
[시트 폴링]  60초마다 시트를 봄 → 새 질문이 있으면 초안 생성 → 슬랙 카드 발송
[슬랙 리스너] [승인]/[수정]/[보류] 버튼을 기다림 → 눌리면 시트에 기록
```

원래 둘은 별개 프로그램이었는데 **한 프로세스로 묶었습니다.** 따로 띄우면 PC를 켤 때마다
두 번 실행해야 하고, 한쪽만 죽어도 알아채기 어렵기 때문입니다.

---

## 2. 옮겨야 할 것 — git 에 없는 파일 둘

**이게 가장 자주 걸리는 지점입니다.** 저장소를 내려받는 것만으로는 동작하지 않습니다.
아래 둘은 비밀 정보라 git 에 올리지 않으므로 **따로 복사**해야 합니다.

| 대상 | 내용 |
|---|---|
| `.env` | API 키, 시트 URL, 슬랙 토큰 |
| `raw/<서비스계정>.json` | 구글 서비스 계정 키 |

`.env` 에 필요한 값은 다섯 개입니다.

```
ANTHROPIC_API_KEY=sk-ant-...
GOOGLE_CREDENTIALS=raw/kbrain-chatbot-xxxxxxxx.json
SHEET_URL=https://docs.google.com/spreadsheets/d/<시트ID>/edit
SLACK_BOT_TOKEN=xoxb-...
SLACK_APP_TOKEN=xapp-...
SLACK_CHANNEL=C0XXXXXXXXX
```

`POLL_INTERVAL` 을 넣으면 폴링 간격(초)을 바꿀 수 있습니다. 기본 60초입니다.

## 3. 설치 절차

### 3-1. uv 설치 (한 번만)

PowerShell 에서:

```powershell
irm https://astral.sh/uv/install.ps1 | iex
```

설치 후 PowerShell 을 닫았다 다시 엽니다.

### 3-2. 프로젝트 내려받기

```powershell
git clone https://github.com/kbrain-hrd/kbrain-chatbot.git
cd kbrain-chatbot
```

### 3-3. `.env` 와 서비스 계정 키 복사

2장의 파일 둘을 프로젝트 폴더에 넣습니다. `raw/` 폴더가 없으면 만드세요.

### 3-4. 의존성 설치

```powershell
uv sync
```

의미 검색 모델(약 471MB)을 처음 실행할 때 자동으로 내려받습니다. 시간이 걸립니다.

### 3-5. 연결 확인

등록하기 전에 시트에 붙는지부터 봅니다. **읽기만 하므로 안전합니다.**

```powershell
uv run python -m backend.sheets.client
```

컬럼 매핑과 미처리 행 수가 나오면 정상입니다. 여기서 실패하면 아래 5장을 보세요.

### 3-6. 자동 시작 등록

```powershell
powershell -ExecutionPolicy Bypass -File install-autostart.ps1
```

관리자 권한은 필요 없습니다. **시작 프로그램 폴더**에 런처를 넣는 방식이라
현재 사용자로 로그온할 때만, 최소화된 창으로 실행됩니다.

### 3-7. 지금 바로 시작

탐색기에서 `run.bat` 을 더블클릭하거나:

```powershell
start "" /min run.bat
```

## 4. 잘 도는지 확인하기

**로그를 봅니다.** 창은 최소화된 채로 떠 있고 화면에 아무것도 찍지 않으므로,
돌아가는 내용을 보는 창구는 로그뿐입니다.

```powershell
Get-Content logs\service.log -Tail 20 -Wait
```

정상이면 이런 줄이 보입니다.

```
[2026-08-03 17:31:23] 셀프스터디 문의 대응 서비스 시작
  슬랙 채널: C0XXXXXXXXX
[2026-08-03 17:31:28] 슬랙 리스너 시작 — 중지는 Ctrl+C
Bolt app is running!
30초 간격 폴링. 중지는 Ctrl+C.
  9행 → 운영 · 초안 · 신뢰도 medium · 카드 발송
[17:32:34] 처리 1행
```

**실제로 시험해 보려면** 시트에 질문을 한 줄 넣고(상태 칸은 비워둔 채) 1분쯤 기다립니다.
슬랙에 카드가 오면 정상입니다.

### 명령 모음

```powershell
start "" /min run.bat                       # 시작 (탐색기에서 더블클릭해도 같음)
                                            # 중지: 서비스 창을 닫는다
Get-NetTCPConnection -LocalPort 57321 -State Listen   # 돌고 있는지 확인 (자물쇠 포트)
$s = "$env:APPDATA\Microsoft\Windows\Start Menu\Programs\Startup\kbrain-chatbot.bat"
Test-Path $s                                # 자동 시작 등록 상태 확인
del $s                                      # 자동 시작 해제
```

중지에 별도 명령이 없는 것은 **창 자체가 서비스이기 때문**입니다. 창을 닫으면 멈춥니다.
창을 찾지 못하겠으면 작업 관리자에서 `python.exe` 를 종료해도 되지만, 그러면 `run.bat` 이
30초 뒤 다시 띄우므로 창까지 닫아야 완전히 멈춥니다.

## 5. 문제가 생기면

| 증상 | 원인과 대처 |
|---|---|
| `SHEET_URL 이 없습니다` | `.env` 가 없거나 프로젝트 폴더 밖에 있습니다 |
| `서비스 계정 키 파일이 없습니다` | `raw/` 의 JSON 을 복사하지 않았습니다 |
| `Office 파일(xlsx)입니다` | 대상이 구글 시트가 아닙니다. `파일 → Google 스프레드시트로 저장` 으로 변환하세요 ([04](04-open-questions.md) 2-9) |
| `시트를 열지 못했습니다` | 서비스 계정이 그 시트에 편집자로 공유돼 있는지 확인하세요 |
| `찾지 못한 컬럼이 있습니다` | 시트 헤더가 바뀌었습니다. 로그에 실제 헤더가 찍히니 대조하세요 |
| 카드가 안 옴 | 슬랙 봇이 채널에 초대돼 있는지(`/invite @봇이름`), `SLACK_CHANNEL` 이 채널 ID(`C…`)인지 확인 |
| 버튼을 눌러도 무반응 | 서비스가 꺼져 있습니다. 로그와 `Get-NetTCPConnection -LocalPort 57321 -State Listen` 를 보세요 |
| `이미 실행 중입니다` | 정상입니다. 서비스는 한 번에 하나만 뜹니다. 기존 것을 멈추려면 그 서비스 창을 닫으세요 |
| 로그온했는데 창이 안 뜸 | 자동 시작 런처가 없거나 깨졌습니다. `install-autostart.ps1` 을 다시 실행하세요 (경로에 한글이 있으면 인코딩 문제가 납니다 — 3-6 참고) |
| 시트 구조를 바꿨는데 반영 안 됨 | 시작할 때 한 번 읽습니다. 서비스를 재시작하세요 |

**프로그램이 죽으면 `run.bat` 이 30초 뒤 다시 띄웁니다.** 다만 같은 오류로 계속 죽으면
로그에 재시작이 반복해 찍히므로, 로그를 보면 알 수 있습니다.

### 네트워크가 끊겨도 멈추지 않습니다

구글 시트 연결이 일시적으로 끊기는 일은 실제로 일어납니다. 그때는 폴링을 멈추지 않고
다음 주기에 다시 시도하며, 로그에 이렇게 남습니다.

```
[14:20:05] 폴링 실패 1회째 (ConnectionError: Connection aborted...) — 60초 뒤 다시 시도합니다
[14:21:05] 폴링 복구됨 (연속 실패 1회 뒤)
```

**5회 연속 실패하면 슬랙으로 알립니다.** 로그는 사람이 열어봐야 보이므로, 담당자가
이미 보고 있는 검수 채널로 보냅니다. 복구되면 복구 알림이 한 번 더 갑니다.

```
⚠️ 시트 폴링이 5회 연속 실패했습니다 — 질문 감지가 멈춰 있습니다.
   ConnectionError: Connection aborted...
   인터넷 연결 · 시트 공유 권한 · 서비스 계정 키를 확인하세요.
```

같은 경고를 반복해 보내지 않습니다(복구될 때까지 한 번만). 채널이 경고로 묻히면
정작 검수 카드를 놓치기 때문입니다.

이 알림을 받으면 **인터넷 연결, 시트 공유 권한, 서비스 계정 키 만료**를 확인하세요.
그 전까지는 손댈 필요가 없습니다 — 알아서 다시 시도합니다.

그래도 회복하지 못해 폴링이 아예 끝나면 **프로세스를 일부러 종료합니다.** 그래야
`run.bat` 이 처음부터 다시 띄웁니다. 프로세스를 살려 두면 슬랙 버튼은 동작하는데
카드만 안 오는 상태가 되어, 문제를 알아채기 어렵습니다.

## 6. 한계

- **PC 가 꺼지거나 절전으로 들어가면 멈춥니다.** 그동안 등록된 질문은 사라지지 않고,
  다시 켜면 미처리 상태이므로 그때 처리됩니다.
- **로그온해야 시작됩니다.** 부팅만 하고 로그인하지 않으면 뜨지 않습니다.
- 24시간 보장이 필요해지면 서버나 클라우드로 옮기면 됩니다. **코드는 그대로 쓰면 됩니다** —
  Socket Mode 라 공개 URL 도, 도메인도, 방화벽 설정도 필요 없습니다.

## 7. 비용

| 항목 | 비용 |
|---|---|
| 서비스 실행 자체 | 0원 (구글 시트·슬랙 API 는 무료) |
| 질문 1건 판정 | 약 12원 |
| 초안 생성까지 가는 건 | 약 99원 추가 |

월 200건 기준 **약 3,400원**입니다. 되묻기·사람확인으로 끝나는 건은 초안 비용이 들지 않습니다.

한 사이클에 최대 20행까지만 처리합니다(`MAX_PER_CYCLE`) — 시트에 질문이 한꺼번에 쌓여도
비용이 예고 없이 튀지 않게 하려는 것이고, 남은 건은 다음 사이클에서 이어 처리됩니다.
