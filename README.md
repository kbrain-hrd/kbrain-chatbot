# kbrain-chatbot

셀프스터디(AI 과목) 문제 및 운영 문의에 대한 **답변 초안 자동 생성 + 사람 검수** 시스템.

기존에 사람이 구글시트에 수기로 작성하던 질의응답을, 챗봇이 근거 기반 초안을 만들고
담당자가 승인하면 자동 등록되는 구조로 전환하는 것이 목표입니다.

---

## 왜 만드는가

- 질문·답변이 구글시트에 쌓이지만 **매번 사람이 수기로 작성**해야 함
- 기존 답변 중 **틀린 것이 섞여 있음**
- 공식 정답·해설조차 **오류가 있어 검수가 필요**한 상태

즉 단순히 "과거 답변을 찾아주는" 시스템으로는 안 되며,
**문제 원문을 기준으로 답을 도출하고, 기존 자료의 오류까지 잡아내는** 구조가 필요합니다.

---

## 핵심 원칙

1. **정답의 근거는 문제 원문** — 과거 답변과 공식 해설은 근거가 아니라 검수 대상
2. **사람 승인 없이 답변이 나가지 않음** — 초안 생성까지만 자동, 등록은 승인 후
3. **모르면 모른다고 함** — 근거가 없거나 판단이 갈리면 초안을 만들지 않고 사람에게 넘김
