# kbrain-chatbot

셀프스터디(AI 과목) 문제 및 운영 문의에 대한 **답변 초안 자동 생성 + 사람 검수** 시스템.

질문은 **구글시트와 유선(전화)** 두 경로로 들어오고, 챗봇이 근거 기반 초안을 만듭니다.
시트 질문은 슬랙에서 승인하면 자동 등록되고, 유선 문의는 담당자가 웹 화면에서
근거와 함께 초안을 보고 즉석에서 답합니다.

---

## 왜 만드는가

- 질문·답변이 구글시트에 쌓이지만 **매번 사람이 수기로 작성**해야 함
- **유선 문의는 그 자리에서 답해야 하는데** 자료를 뒤질 시간이 없음
- 기존 답변 중 **틀린 것이 섞여 있음**
- 공식 정답·해설조차 **오류가 있어 검수가 필요**한 상태

즉 단순히 "과거 답변을 찾아주는" 시스템으로는 안 되며,
**문제 원문을 기준으로 답을 도출하고, 기존 자료의 오류까지 잡아내는** 구조가 필요합니다.

---

## 핵심 원칙

1. **정답의 근거는 문제 원문** — 과거 답변과 공식 해설은 근거가 아니라 검수 대상
2. **사람 승인 없이 답변이 나가지 않음** — 초안 생성까지만 자동, 등록은 승인 후.
   유선도 예외가 아닙니다. 담당자 본인이 실시간 검수자이고, 챗봇 출력이 사람을 거치지 않고
   질문자에게 도달하는 경로는 없습니다.
3. **모르면 모른다고 함** — 근거가 없거나 판단이 갈리면 초안을 만들지 않고 사람에게 넘김

예제문제(그린·블루 각 5세트 × 3과목)와 운영 자료 4종을 확인했고,
그 결과 설계 가정 몇 가지를 수정했습니다 — 자세한 내용은
[05-data-survey.md](docs/05-data-survey.md) 참조.

주요 변경:
- 앵커 스킴이 `R01-Q03` → `G-S01-M02-Q03` (등급·세트·과목·문항)
- 단답 문항이 100개 규모라 **벡터 검색 미사용**, 앵커 조회로 확정
- PDF 추출기는 **두 종을 대조** — pdfplumber는 답안지 숫자를 누락하고, pypdfium2는 인접 셀 숫자를 병합함
- 3과목은 정답이 없는 산출물 평가 — 별도 경로 필요

이후 추가 결정 (2026-08-01):
- **유선 대응 경로 추가.** 웹 UI에서 근거와 함께 초안을 보고 담당자가 즉석 응대
- **승인은 슬랙, 수정은 시트.** 당초 "시트에서 검수" 권장안에서 변경
- 자료가 계속 추가되므로 인제스트는 재실행 가능한 파이프라인으로 작성

미수령: 구글시트(과거 질의응답). 유선 경로(1~5단계)는 시트 없이 진행 가능합니다.
