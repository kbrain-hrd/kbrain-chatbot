# kbrain-chatbot

셀프스터디(AI 과목) 문제 및 운영 문의에 대한 **답변 초안 자동 생성 + 사람 검수** 시스템.

질문은 **구글시트와 유선(전화)** 두 경로로 들어오고, 챗봇이 근거 기반 초안을 만듭니다.
시트 질문은 슬랙에서 승인하면 자동 등록되고, 유선 문의는 담당자가 웹 화면에서
근거와 함께 초안을 보고 즉석에서 답합니다.

---

## 왜 만드는가

- 질문·답변이 구글시트에 쌓이지만 **매번 사람이 수기로 작성**해야 함
- **유선 문의는 그 자리에서 답해야 하는데** 자료를 뒤질 시간이 없음
- 기존 답변 중 **틀린 것이 섞여 있음**
- 공식 정답·해설조차 **오류가 있어 검수가 필요**한 상태

즉 단순히 "과거 답변을 찾아주는" 시스템으로는 안 되며,
**문제 원문을 기준으로 답을 도출하고, 기존 자료의 오류까지 잡아내는** 구조가 필요합니다.

---

## 핵심 원칙

1. **정답의 근거는 문제 원문** — 과거 답변과 공식 해설은 근거가 아니라 검수 대상
2. **사람 승인 없이 답변이 나가지 않음** — 초안 생성까지만 자동, 등록은 승인 후.
   유선도 예외가 아닙니다. 담당자 본인이 실시간 검수자이고, 챗봇 출력이 사람을 거치지 않고
   질문자에게 도달하는 경로는 없습니다.
3. **모르면 모른다고 함** — 근거가 없거나 판단이 갈리면 초안을 만들지 않고 사람에게 넘김

## 어떻게 동작하는가

```
질문 도착 (시트 or 유선)
      ↓
  [찾기]  앵커 카탈로그에서 고르기 — 검색이 아니다
      ↓
  [로드]  확정된 앵커의 파일만
      ↓
  [제시]  초안 + 근거 인용 + 플래그 + 신뢰도
      ↓
  사람 검수 — 승인 없이는 나가지 않음
```

### 찾기 — 문항은 목록에서 고르고, 운영은 검색한다

문항 100개는 **앵커 카탈로그를 통째로** 프롬프트에 넣고 그 목록에서 어느 줄인지
지목하게 합니다. 카탈로그 한 줄은 이렇습니다.

```
| `G-S04-M02-Q02` | 18 | 노쇼(예약부도) 건수는 몇 건입니까? | 790 | 노쇼여부 == "노쇼" |
    앵커            배점  질문                                 정답   근거
```

조각을 유사도로 끌어오는 방식이 아니어서 **고르는 순간 출처가 확정**됩니다.
문항에서 이 방식을 고수하는 이유는 세 가지입니다 — 그린·블루는 숫자만 달라 검색으로
가를 수 없고, 주력 동작인 되묻기를 상위 N개 목록으로 표현할 수 없으며,
**공식 정답 오류 경고가 매 질의 항상 보이는 것**이 전량 적재라서 가능합니다.

운영 섹션 119개는 반대입니다. 등급 개념도 되묻기도 없어 **BM25로 검색해 상위 12개만**
싣습니다. 자료가 아무리 쌓여도 판정 프롬프트가 커지지 않습니다.
결정 근거는 [04-open-questions](docs/04-open-questions.md) 2-7 참조.

### 등급을 모르면 반드시 되묻는다

그린과 블루는 **세트명·주제가 같고 정답만 다릅니다.** 질문이 "3세트 2과목"까지만
밝히면 앵커를 `?-S03-M02` 로 두고 등급을 되묻습니다. 추측하지 않습니다.

실제 질문 25건 중 등급을 밝힌 것은 **2건뿐**이라, 되묻기는 예외가 아니라 기본 동작입니다.

### 제시 — 정답이 아니라 갈린 지점을 짚는다

응시자는 이미 AI로 풀어보고 옵니다(문제지에 "AI 챗봇 자유 활용" 명시). 그래서 필요한 것은
정답 숫자가 아니라 **어디서 갈렸는지**입니다.

> **질문** 4세트 2과목 2번 노쇼 건수를 세는데 0이 나옵니다.
>
> **초안** 노쇼여부 값이 `Y`/`1` 이 아니라 **`노쇼`/`정상`** 문자열입니다. `Y` 로 세면
> 일치하는 행이 없어 0이 나옵니다. 정답은 790이며, 정상 710건과 합하면 1500으로 맞습니다.

초안에는 **근거 인용**(어느 파일 어느 대목), **플래그**(`해설불일치` `근거부족`
`공식정답오류` `판정보류`), **신뢰도**(high/medium/low)가 함께 붙습니다.

### 못 답하는 쪽으로 실패한다

| 상황 | 동작 |
|---|---|
| 등급 불명 | 되묻기 |
| 근거 없음 | 초안 생성 안 함 + `근거부족` |
| 판단 갈림 | 대조 결과만 제시하고 사람에게 |
| 자료 오류 의심 | 판정하지 않음 + `공식정답오류` |

**못 답하는 것은 허용, 틀린 답을 확신 있게 제시하는 것은 불허.**

### 자료를 다루며 확인된 것들

- **공식 정답에 오류가 있었습니다.** 5세트 1과목 5문항에 대해 출제기관이 오류를 인정하고
  수정 예정입니다. 카탈로그 최상단에 경고로 표시되며, 해당 문항은 판정하지 않습니다
  — [05-data-survey](docs/05-data-survey.md) 6-2
- **PDF 추출기 두 종이 서로 다르게 틀립니다.** pdfplumber는 답안지 숫자를 누락하고,
  pypdfium2는 인접 셀 숫자를 병합합니다(`15 4` → `154`). 답안지는 두 결과를 대조해
  사람이 확정했습니다
- **셀프학습 가이드에 FAQ가 있습니다.** 인증 방식·합격 기준(75점)·평가 일정·재응시가
  한 섹션에 정리돼 있어 운영 문의의 핵심 근거입니다
- **응시자 이의 제기가 삼각 검증의 네 번째 입력입니다.** 블라인드 풀이가 답안지와
  일치해도 문제 자체가 틀릴 수 있다는 것이 실증됐습니다
